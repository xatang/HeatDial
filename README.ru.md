# HeatDial

[English](README.md)

HeatDial подсказывает, когда стоит повернуть ручку котла. Он читает температуры и записанное положение ручки, затем советует оставить текущее деление, прибавить или убавить.

## Установка

В Home Assistant откройте **Настройки → Marketplace → Добавить по ссылке**, укажите `xatang/HeatDial` и установите интеграцию. Если Home Assistant предложит перезапуск, выполните его, затем добавьте **HeatDial** в разделе **Настройки → Устройства и службы**. Требуется Home Assistant 2026.11 или новее.

## Первичная настройка

- Выберите числовой помощник для записи положения ручки. Обновляйте его после каждого поворота.
- Выберите уличный термометр и источник почасового прогноза, если он есть.
- Добавьте датчики комнат во вкладке **Настройки**. Вес 1 даёт обычную реакцию. При весе ниже 1 HeatDial дольше проверяет охлаждение, а при весе выше 1 реагирует быстрее. Комната с весом 0 видна на странице и исключена из расчёта.
- Настройте дневной диапазон, ночной минимум, окно для снижения и вечернюю проверку. Каждая строка шкалы задаёт доступное деление. Температуру воды можно указать примерно или оставить пустой. За один раз HeatDial советует изменить нагрев на одно деление.
- Для начала оставьте включённым режим наблюдения. В нём советы видны на странице, а события для уведомлений приостановлены.

Размещайте датчики на сопоставимой высоте, подальше от батарей, прямых солнечных лучей и сквозняков.

## Страница HeatDial

Откройте **HeatDial** в боковом меню Home Assistant или через **Настройки → Устройства и службы → Интеграции → HeatDial**. Страница поставляется вместе с интеграцией. Русский и английский выбираются по языку профиля Home Assistant.

- **Обзор** показывает совет, причину, положение ручки, температуру в комнатах и данные о погоде.
- **История** показывает температуру в комнатах и на улице, деления и смену рекомендаций за 24 часа, три дня или неделю.
- **Настройки** позволяют менять температурные границы, расписание, датчики, шкалу делений и режим наблюдения.

## Как появляется совет

HeatDial ждёт, пока причина повернуть ручку сохраняется 20 минут. При резком охлаждении одной комнаты он даёт температуре стабилизироваться. После записанного поворота ручки оценивает результат через три часа.

Во время вечерней проверки HeatDial учитывает длительное похолодание. Он корректирует ближайшие часы прогноза по уличному датчику и учитывает несколько прогнозных точек, чтобы одиночный скачок не повлиял на совет.

При запуске HeatDial берёт до пяти часов истории из Recorder, в том числе для только что выбранных датчиков. Если для приоритетных комнат не хватает 30 минут пригодных замеров, он сначала собирает недостающую историю. При недоступности прогноза система продолжает учитывать местные замеры. Для рекомендации убавить нужен свежий уличный замер.

## Объекты и уведомления

- `sensor.heatdial_recommendation` — действие и данные, на которых основан совет.
- `sensor.heatdial_recommended_dial` — текущее положение, которое стоит оставить, или новое деление.
- `sensor.heatdial_reason` — причина на языке интерфейса.

Для уведомлений на телефоне добавьте в автоматизацию триггер **Получено событие** для `event.heatdial_adjustment` и действие мобильного приложения. В событии есть `event_type`, `from_dial`, `to_dial`, `reason` и, если применимо, `room`. Между событиями проходит минимум три часа. Повтор того же совета без поворота возможен через восемь часов. Чтобы события начали поступать, выключите режим наблюдения.

## Разработка

Проверки логики выполняются командой `python -B -m unittest discover -s tests -v` и работают без запущенного Home Assistant.
